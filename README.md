# やりたいことリストアプリ

自分の「人生でやりたいこと」を登録・管理できるWebアプリです。

以前、何のために頑張っているのか分からなくなり、
目標を見失っていた時期がありました。

そんな中で「bucket list」という考え方に出会い、
やりたいことを見つけて言語化するだけで、
そのために頑張る力が湧いてくることに気づきました。
仕事も勉強も、目的があると苦にならず、
人生が前向きになっていく感覚がありました。

同じように目標を見失っている人にも、
この感覚を味わってもらいたいと思い、このアプリを作りました。
思いついた瞬間の気持ちを逃さず記録できるツールとして
使ってもらえたら嬉しいです。

## 今後追加したい機能

- ユーザーごとのログイン機能(認証)
- やりたいことを追加した日時の記録
- 追加したときの気持ちを自由記述できる備考欄
- 気持ちに合わせて選べるスタンプ機能
- 達成時の演出(スペシャルな表示)
- ジャンルごとの分類・色分け表示
- フロント画面からの達成・削除操作
